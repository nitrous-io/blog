Earlier this year, we re-architected our [desktop app](https://www.nitrous.io/desktop)
from the ground up and released it for both [Windows](https://www.nitrous.io/desktop#windows)
and [Mac](https://www.nitrous.io/desktop#mac) platforms.

The desktop app was written using the same technologies that power our
Web IDE &mdash; namely, Ember.js and HTML5. This not only allowed us to
reuse code from our Web IDE, but also to have one code-base that works
on both Windows and Mac.

Yesterday, at Ember&rsquo;s monthly meetup in San Francisco, we shared
some of the insights we gained from building our desktop application
with Ember.js and Node-webkit.
