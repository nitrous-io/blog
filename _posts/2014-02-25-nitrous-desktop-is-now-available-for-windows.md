Despite being the platform with the largest market share, Microsoft
Windows hasn't exactly been very popular amongst the new generation of
developers.  If you develop on Windows, the feeling of being neglected
shouldn't be unfamiliar to you.

<!--break-->

Sexy new programming languages, frameworks, and open-source utilities
often treat Windows platform as a second-class citizen, and their
documentation, tutorials, and help articles are seldom useful to
Windows developers because they are written for developers that use
Unix-like operating systems.

Take a look at [generating SSH keys](http://help.nitrous.io/ssh-windows/)
for example.  On Mac or Linux, it is a simple one-liner in the command
line that does the job, but Windows, it is a convoluted process that
involves downloading and installing some third-party software.  Trying to
SSH into your box?  Same story.  Ever wanted to contribute to [a popular open-source
project](http://edgeguides.rubyonrails.org/contributing_to_ruby_on_rails.html)?
Again it assumes you have access to a Unix shell.

So what is the solution?  While brandishing the latest [MacBook Pro](http://www.apple.com/macbook-pro/)
certainly seems to have worked well for [a lot of people](http://www.flickr.com/photos/placenamehere/6345397641/),
at Nitrous.IO, we believe in democratizing development environments, so
we would like to present our first attempt at leveling the playing field.

Today we are releasing Nitrous Desktop for Windows, which is
[available for a free download](https://www.nitrous.io/desktop?{{ page.utm }}) effective
immediately.  So stop procrastinating and start coding with your
favorite text editor with access to powerful Linux shell on your Windows
desktop now, and have fun!
