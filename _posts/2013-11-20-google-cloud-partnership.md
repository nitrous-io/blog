#### Google Cloud Platfom + Nitrous.IO 
We're excited announce that Nitrous.IO has joined Google Cloud Platform Partner Program as a Technology Partner.

Developers creating and managing their development environments on the web at [Nitrous.IO](http://nitrous.io/?utm_source=nitrous+utm_medium=blog+utm_content=gcpp) or through the highly rated [Chrome App]( https://chrome.google.com/webstore/detail/nitrousio-web-app/kcbmakmdbnehgbakmgibcpjpafenmohd?utm_source=nitrous.io+utm_medium=blog+utm_content=gcpp) can deploy directly to production using [Google App Engine](https://developers.google.com/appengine/?ref=nitrous.io+utm_source=nitrous.io+utm_medium=blog+utm_content=gcpp) (GAE). 
The built-in GAE Command Line Interface (CLI) included in each Nitrous.IO Development box allows a entirely web based development flow improving time to market and minimizing friction associated with incompatible developement and production environments.    

####Google Cloud Platform Starter Pack
Additionally, with this partnership we're pleased to announce that Nitrous.IO users can qualify for a [Google Cloud Platform Starter Pack](https://cloud.google.com/resources/starterpack/) which 
includes $2,000 of credit on the Google Cloud Platform - $1,000 for Google App Engine and $1,000 for Google Compute Engine. 

Email us at partners@nitrous.io if you would like to take advantage of this offer.
